## Initial setup

> [!CAUTION]
> Make sure not to commit any sensitive information

Before you start, there is a few things you need to setup:

1. Setting up an account in [spotify for developers](https://developer.spotify.com) and create a spotify app.
2. Copy the values for `SPOTIPY_CLIENT_ID`, `SPOTIPY_CLIENT_SECRET` and `SPOTIPY_REDIRECT_URI` once the app is created
3. Create a configuration `.json` file that looks something like this:

```json
{
  "id": "user-id-123",
  "auth": {
    "client_id": "your-client-id",
    "client_secret": "your-client-secred",
    "redirect_uri": "your-callback-uri"
  },
  "spotify_user_name": "spotify-user-name",
  "playlists": [
    {
      "id": "0ZhTd0v0esEM40nX1S66g0",
      "url": "https://open.spotify.com/playlist/0ZhTd0v0esEM40nX1S66g0?si=5a7c2e558ea84bfc",
      "name": "STMPD RCRDS New Releases",
      "allowed_tracks": 2
    },
    {
      "id": "4oOZJEq1TBUti6PSouTo5M",
      "url": "https://open.spotify.com/playlist/4oOZJEq1TBUti6PSouTo5M?si=af1d23279d664320",
```
